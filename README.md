# HAIR DAY Website

เว็บไซต์ร้านยาสระผม HAIR DAY

## ไฟล์ใน Repository
- `index.html` — หน้าเว็บไซต์หลัก
- รูปภาพสินค้าเป็น SVG ที่ฝังอยู่ในไฟล์ HTML จึงไม่มีโฟลเดอร์รูปภาพแยกในชุดนี้

## วิธีเปิดเว็บไซต์
เปิด `index.html` ด้วยเว็บเบราว์เซอร์ หรือเชื่อม Repository นี้กับ Vercel เพื่อเผยแพร่เว็บไซต์

## ข้อมูลสินค้าในเวอร์ชันนี้
- PH001 — PURE HAIR Daily Shampoo — 159 บาท
- PH002 — PURE HAIR Botanical Shampoo — 189 บาท

## ข้อจำกัดที่ควรทราบก่อนใช้งานจริง
- ข้อมูลสินค้าอยู่ใน JavaScript ภายใน `index.html` ยังไม่ได้ดึงข้อมูลจาก Google Sheets
- รายการคำสั่งซื้อและตะกร้าใช้ Local Storage ของเบราว์เซอร์ จึงไม่ได้ส่งข้อมูลไปเก็บใน Google Sheets หรือฐานข้อมูลกลาง
- เวอร์ชันนี้ไม่มีระบบหลังบ้านสำหรับดูคำสั่งซื้อจากอุปกรณ์อื่น
